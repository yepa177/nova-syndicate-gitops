 Fork et le Clone --> defference entre les 2 : 

 fork --> c'est pour réccuperer une image distribué du projet ( qui est sur vos platform de colaboration tel que GitHub ou GitLab, ...) par exemple Kubernetes comme un nouveau repertoire sur votre machine. 
 Clone --> pour réccuperer le projet (download via lien qui se trouve sur code ex: " git clone https://github.com/yepa177/kubernetes.git") qui tjrs connecté a un repository en ligne a installer sur votre machine via cli "git clone https://github.com/kubernetes/kubernetes" et cd kubernetes puis make .
